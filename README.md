# Vigilant Forensic Research and Analytics Pvt. Ltd. (VFRA)

Official website repository for Vigilant Forensic Research and Analytics Pvt. Ltd. — a digital forensics and cyber investigation firm focused on structured investigative methodologies, evidence integrity, and professional reporting standards.

---

## Overview

This project contains the source code for the official VFRA website. The platform showcases:

- Digital Forensics Services
- Cybercrime Investigation Support
- Incident Response Capabilities
- Training & Workshops
- Contact & Consultation System (Supabase-backed)
- Structured Content Management Hooks

The application is built with a modern, scalable frontend architecture.

---

## Tech Stack

- Vite  
- React  
- TypeScript  
- Tailwind CSS  
- shadcn/ui  
- Supabase (Backend & Database)

---

### Directory Description

- `pages/` → Application routes  
- `components/` → Reusable UI components  
- `hooks/` → Content and logic hooks  
- `lib/` → Supabase configuration  
- `assets/` → Images and media
